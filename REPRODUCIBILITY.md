# Reproducibility Readiness Checklist

Checklist for ensuring the repository is ready for public GitHub release and meets
journal standards (e.g., Nature Methods Gold-tier reproducibility). Run through
this list before every release.

**Last updated**: 2026-06-17
**Next review**: Before public release / arXiv submission

---

## 1. Repository Structure & Organization

- [ ] **1.1** Clear top-level directory layout (README or doc shows tree with `tree -L 2`)
- [ ] **1.2** Separate `data/` (downloaded), `methods/` (code), `benchmarks/` (experiments), `results/` (outputs)
- [ ] **1.3** Raw data treated as read-only; processed data kept separate
- [ ] **1.4** Scripts run in logical order with numbered prefixes or a single driver script
- [ ] **1.5** Consistent file naming: `snake_case` throughout, no spaces or special chars
- [ ] **1.6** No stale/dead files from prior experiments (old logs, orphaned results, WIP scripts)
- [ ] **1.7** `plan.md` excluded from public repo (in `.gitignore` ✓)

## 2. README — First Impression & Central Hub

- [ ] **2.1** One-paragraph project summary with paper DOI/link (if available)
- [ ] **2.2** Directory overview showing what lives where
- [ ] **2.3** Hardware requirements: RAM, GPU VRAM, disk space, CPU cores
- [ ] **2.4** Software requirements: OS, Python version, key system deps (e.g., Apptainer)
- [ ] **2.5** Quick start: ≤5 copy-paste commands from clone → first result
- [ ] **2.6** Expected output shown (e.g., "Pearson ~0.990 for Liver")
- [ ] **2.7** Links to full docs: QUICKSTART.md, REPRODUCIBILITY.md, CONTRIBUTING.md
- [ ] **2.8** Badges: CI status, license, Python version, Zenodo DOI

## 3. Licensing & Metadata

- [ ] **3.3** Repository archived on Zenodo / Figshare with persistent DOI
- [ ] **3.4** GitHub repo metadata: description, website, topic tags (`deconvolution`, `single-cell`, `benchmark`, etc.)
- [ ] **3.5** `CODE_OF_CONDUCT.md` present
- [ ] **3.6** `CONTRIBUTING.md` present (✓)

## 4. Dependency Management & Environment

- [ ] **4.1** **Conda environment file** (`environment.yml`) with exact pinned versions
  - **Currently**: versions are ranges (e.g., `python>=3.10,<3.12`, `pytorch>=2.1.0`)
  - **Required**: `environment.lock.yml` with `conda env export --no-builds` exact pins, OR add minimum version floor for all packages
- [ ] **4.2** **pip requirements** pinned: `requirements.txt` with `==` for all direct deps
- [ ] **4.3** `pyproject.toml` lists all runtime dependencies (not just build deps)
- [ ] **4.4** **GPU variant documented**: how to add CUDA toolkit to the environment
- [ ] **4.5** **Container image** (Dockerfile or Apptainer `.def`) for the core package so users can run without Conda
- [ ] **4.6** `ldconfig` / `LD_LIBRARY_PATH` caveats documented (CXXABI issues known in CLAUDE.md)
- [ ] **4.7** One-command install tested on a clean machine: `conda env create -f environment.yml && pip install -e .`

## 5. Data Availability

- [ ] **5.1** All datasets have public download URLs (not internal GPFS paths or `/fast/` mounts)
- [ ] **5.2** `data/download_data.sh` fetches everything without errors
- [ ] **5.3** SHA256 checksums provided for every downloaded file and verified in the script
- [ ] **5.4** Data manifest (`data/manifest.yaml`) lists: filename, size, SHA256, source URL, license
- [ ] **5.5** Pre-trained model weights downloadable from public URLs (scGPT, Geneformer, etc.)
- [ ] **5.6** No protected/restricted data (CELLxGENE, Tabula-Sapiens, TCGA, GEO are all public)
- [ ] **5.7** Small test dataset included (or generated by script) for quick smoke tests
- [ ] **5.8** Data availability statement in README with DOIs for all external datasets

## 6. Reproducible Code

## Quick Audit Commands

```bash
# Find hardcoded paths
grep -r '/gpfs/flash/home/\|/fast/\|/home/yr/' --include='*.py' --include='*.sh' --include='*.yaml' .

# Check for secrets
grep -rE '(api_key|token|password|secret)' --include='*.py' --include='*.yaml' . | grep -v '#' | grep -v placeholder

# Check for large files in git
git ls-files -z | xargs -0 -I{} du -h {} 2>/dev/null | awk '$1 ~ /M/ && $1+0 > 5 {print}'

# Verify all .def files build (dry-run check they exist)
find containers/ -name '*.def' | while read f; do echo "=== $f ===" && head -5 "$f"; done

# Count methods with run.py entry points
find methods/ -name 'run.py' -maxdepth 2 | wc -l

# Run lint
ruff check . --statistics
```
